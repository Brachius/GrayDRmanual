# Wait

Script name: `wait`

Pause a script sequence for a number of seconds.

## How to start it

Type `.wait` followed by the words it takes.

Enter the number of seconds to pause. This is commonly used inside Multi as :wait N.

Example:

```
.wait 5
```

In Master Train, pick **Wait** as the activity and put the same words in its Arguments box.

## Settings

This script has no settings of its own. Shared pages such as [Character](../studio/character.md), [Magic](../studio/magic.md) and [Crafting](../studio/crafting.md) may still apply.
