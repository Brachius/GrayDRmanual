# Tarantula

Script name: `tarantula`

Consume eligible field experience with a biomechanical tarantula or harvester spider.

## How to start it

Type `.tarantula` in the game window.

In Master Train, pick **Tarantula** as the activity and put the same words in its Arguments box.

## Settings

On the Configuration Studio page [Tarantula](/studio/tarantula.md):

| Setting | What it does | Default | Applies to |
|---|---|---|---|
| <span id="setting-activities-tarantula-no-use-scripts"></span>**Activities that block Tarantula** | A list of activity names. | (not set) | Global, or each character |
| <span id="setting-activities-tarantula-excluded-skills"></span>**Excluded alternate skills** | A list of skill names. | (not set) | Global, or each character |
| <span id="setting-activities-tarantula-skillsets"></span>**Preferred skills by skillset** | A table of name and value pairs. | (not set) | Global, or each character |
| <span id="setting-activities-tarantula-skip-alternate"></span>**Skip unlisted alternate skills** | Yes or No. | No | Global, or each character |
| <span id="setting-activities-tarantula-startup-delay"></span>**Startup delay in seconds** | A number, at least 0. | 15 | Global, or each character |
| <span id="setting-activities-tarantula-noun"></span>**Tarantula item** | Exact item text | harvester spider | Global, or each character |
