# handoff-receive

Script name: `handoff-receive`

The receiver's side of a handoff when his Master Train is not running. It is started on his window by the giver's script; you do not start it yourself.

## How to start it

Type `.handoff-receive` in the game window.

## Settings

This script has no settings of its own. Shared pages such as [Character](../studio/character.md), [Magic](../studio/magic.md) and [Crafting](../studio/crafting.md) may still apply.
