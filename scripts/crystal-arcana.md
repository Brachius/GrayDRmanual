# crystal-arcana

Script name: `crystal-arcana`

Gazes into the worn sanowret crystal once, for Arcana. A Master Train before-step or after-step more than a script to run by hand.

## How to start it

Type `.crystal-arcana` in the game window.

## Settings

This script has no settings of its own. Shared pages such as [Character](/studio/character.md), [Magic](/studio/magic.md) and [Crafting](/studio/crafting.md) may still apply.
