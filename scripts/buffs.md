# buffs

Script name: `buffs`

Casts a named buff set once. `.buffs` casts the set called default, `.buffs hunt` casts the set called hunt. Add `force` to recast everything even if it is active, `strict` to keep going until every buff sticks, `list` to show this character's sets, or `set=name` to list the spells in one set. The sets come from the Buff configuration on the Magic page. Master Train uses the same activity for pre-hunt buffing.

## How to start it

Type `.buffs` in the game window.

## Settings

This script has no settings of its own. Shared pages such as [Character](/studio/character.md), [Magic](/studio/magic.md) and [Crafting](/studio/crafting.md) may still apply.
