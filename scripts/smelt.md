# Smelt

Script name: `smelt`

Work a loaded crucible until the metal is mixed, exactly like smelt.lic.

## How to start it

Type `.smelt` followed by the words it takes.

Leave blank to smelt a crucible you loaded yourself. Type refine to pour flux over an ingot already in the crucible. Type help for the full procedure.

Example:

```
.smelt refine
```

In Master Train, pick **Smelt** as the activity and put the same words in its Arguments box.

## Settings

This script has no settings of its own. Shared pages such as [Character](/studio/character.md), [Magic](/studio/magic.md) and [Crafting](/studio/crafting.md) may still apply.
