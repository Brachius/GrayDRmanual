# Augmentation Magic Training

Script name: `aug-train`

Train Augmentation magic using the script-owned spell configuration (the Augmentation entry under Training spells); stops at mind lock like utility-train and ward-train.

## How to start it

Type `.aug-train` in the game window.

In Master Train, pick **Augmentation magic** as the activity and put the same words in its Arguments box.

## Settings

This script has no settings of its own. Shared pages such as [Character](../studio/character.md), [Magic](../studio/magic.md) and [Crafting](../studio/crafting.md) may still apply.
