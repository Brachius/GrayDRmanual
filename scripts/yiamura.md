# Yiamura

Script name: `yiamura`

Operates a worn yiamura: `.yiamura raise`, `point`, `observe`, `invoke` or `reset`. The hunt raises it by itself; the knowledge it gathers is collected by Yiamura Claim.

## How to start it

Type `.yiamura` in the game window.

In Master Train, pick **Yiamura** as the activity and put the same words in its Arguments box.

## Settings

This script has no settings of its own. Shared pages such as [Character](/studio/character.md), [Magic](/studio/magic.md) and [Crafting](/studio/crafting.md) may still apply.
