# lichroom

Script name: `lichroom`

Translates between GrayDR room numbers and Lich map numbers, for reading old Lich scripts or notes.

```
.lichroom               this room
.lichroom 2026011       the Lich number for that room
.lichroom lich 8908     the GrayDR number for that Lich room
```

## How to start it

Type `.lichroom` in the game window.

## Settings

This script has no settings of its own. Shared pages such as [Character](/studio/character.md), [Magic](/studio/magic.md) and [Crafting](/studio/crafting.md) may still apply.
