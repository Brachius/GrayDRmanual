# Memory Orbs

Script name: `memory-orbs` (also starts as `orbs`)

Invokes or studies memory orbs and puts the orbs that were not used back in their container. An orb that cannot be used goes to the trash bin room from the Character page.

## How to start it

Type `.memory-orbs` in the game window.

In Master Train, pick **Memory Orbs** as the activity and put the same words in its Arguments box.

## Settings

On the Configuration Studio page [Memory Orbs](../studio/memory-orbs.md):

| Setting | What it does | Default | Applies to |
|---|---|---|---|
| **Memory orb handling** |  |  | Global, or each character |
| &nbsp;&nbsp;&nbsp;&nbsp;↳ **Orb item** |  | memory orb | Global, or each character |
| &nbsp;&nbsp;&nbsp;&nbsp;↳ **Source container** _(required)_ |  | (not set) | Global, or each character |
| &nbsp;&nbsp;&nbsp;&nbsp;↳ **Temporary processed container** _(required)_ |  | (not set) | Global, or each character |
