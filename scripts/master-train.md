# master-train

Script name: `master-train`

Runs your whole training routine, card by card, as set up on the Studio's [Master Train page](../studio.md#the-master-train-page). Every command it takes is in [Typed commands](../commands.md#master-train).

## How to start it

Type `.master-train` in the game window.

## Settings

This script has no settings of its own. Shared pages such as [Character](../studio/character.md), [Magic](../studio/magic.md) and [Crafting](../studio/crafting.md) may still apply.
