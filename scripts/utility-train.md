# Utility Magic Training

Script name: `utility-train`

Train Utility magic using the script-owned spell configuration.

## How to start it

Type `.utility-train` in the game window.

In Master Train, pick **Utility magic** as the activity and put the same words in its Arguments box.

## Settings

This script has no settings of its own. Shared pages such as [Character](../studio/character.md), [Magic](../studio/magic.md) and [Crafting](../studio/crafting.md) may still apply.
