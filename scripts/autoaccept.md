# autoaccept

Script name: `autoaccept`

Waits for anyone to offer you something, accepts it, stows it from the right hand, and waits for the next offer. Accepts from anyone. Stop it with `.k autoaccept`.

## How to start it

Type `.autoaccept` in the game window.

## Settings

This script has no settings of its own. Shared pages such as [Character](/studio/character.md), [Magic](/studio/magic.md) and [Crafting](/studio/crafting.md) may still apply.
