# Carving

Script name: `carve`

Native port of carve.lic.

## How to start it

Type `.carve` followed by the words it takes.

chapter recipe material type noun, or resume type noun

Example:

```
.carve 5 "stone bowl" alabaster deed bowl
```

In Master Train, pick **Carving** as the activity and put the same words in its Arguments box.

## Settings

This script has no settings of its own. Shared pages such as [Character](../studio/character.md), [Magic](../studio/magic.md) and [Crafting](../studio/crafting.md) may still apply.
