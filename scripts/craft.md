# Craft Training

Script name: `craft`

Native rank-tier training port of craft.lic; knitting delegates to Sew.

## How to start it

Type `.craft` followed by the words it takes.

forging|outfitting|engineering|alchemy|enchanting [debug]

Example:

```
.craft outfitting
```

In Master Train, pick **Craft Training** as the activity and put the same words in its Arguments box.

## Settings

On the Configuration Studio page [Crafting](../studio/crafting.md):

| Setting | What it does | Default | Applies to |
|---|---|---|---|
| **Craft training rooms** | A list of room names. | (not set) | Global, or each character |
| **Maximum crafting mindstate** | A number, at least 0, at most 34. | 31 | Global, or each character |
| **Rank-tier recipe overrides** |  |  | Global, or each character |
