# Weave Cloth

Script name: `weave-cloth`

Weave two thread items into cloth at a town tailoring society.

## How to start it

Type `.weave-cloth` in the game window.

In Master Train, pick **Weave Cloth** as the activity and put the same words in its Arguments box.

## Settings

This script has no settings of its own. Shared pages such as [Character](/studio/character.md), [Magic](/studio/magic.md) and [Crafting](/studio/crafting.md) may still apply.
