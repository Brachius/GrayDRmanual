# repair-pickup

Script name: `repair-pickup`

Gives every repair ticket back, waits when a repair is not ready, stores returned gear (tied for belt tools, stowed otherwise), and wears everything from the worn-gear sack, which must report empty before it is thrown in the repairer's bucket. It never leaves the repairer's room. A sack that cannot be proven empty stops it with the sack in hand.

## How to start it

Type `.repair-pickup` in the game window.

## Settings

This script has no settings of its own. Shared pages such as [Character](../studio/character.md), [Magic](../studio/magic.md) and [Crafting](../studio/crafting.md) may still apply.
