# profit-tracker-service

Script name: `profit-tracker-service`

The background half of the Profit Tracker. Started by GrayDR when the tracker is enabled on the Profit Tracker page; you do not start it yourself.

## How to start it

Type `.profit-tracker-service` in the game window.

## Settings

This script has no settings of its own. Shared pages such as [Character](../studio/character.md), [Magic](../studio/magic.md) and [Crafting](../studio/crafting.md) may still apply.
