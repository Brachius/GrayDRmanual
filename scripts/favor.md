# favor

Script name: `favor`

Gets a favor: the temple puzzle for one orb, then the altar. `.favor Immortal` names the immortal; otherwise the Theurgy page's aspect is used. Buys a primer when it needs one.

## How to start it

Type `.favor` in the game window.

## Settings

This script has no settings of its own. Shared pages such as [Character](/studio/character.md), [Magic](/studio/magic.md) and [Crafting](/studio/crafting.md) may still apply.
