# tendme

Script name: `tendme`

Tends your own wounds: only parasites, lodged objects and bleeders that are safe to tend, most severe first. `.tendme train` unwraps and rebinds wounds for learning; `.tendme monitor` keeps running to keep bleeders tended.

## How to start it

Type `.tendme` in the game window.

## Settings

This script has no settings of its own. Shared pages such as [Character](/studio/character.md), [Magic](/studio/magic.md) and [Crafting](/studio/crafting.md) may still apply.
