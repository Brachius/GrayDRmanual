# Medic Plant

Script name: `medic-plant`

Maintains and fully drains the Empath's bonded vela'tohr plant in the medic room. Words, all optional: `room=number`, `set=name`, `healing-set=name`, `recovery-set=name`, `recast=n`, `max-score=n`, `resume-score=n`, `foc-score=n`, `min-vitality=n`, `keep-regen`, `once`, `debug`.

## How to start it

Type `.medic-plant` in the game window.

In Master Train, pick **Medic Plant** as the activity and put the same words in its Arguments box.

## Settings

This script has no settings of its own. Shared pages such as [Character](/studio/character.md), [Magic](/studio/magic.md) and [Crafting](/studio/crafting.md) may still apply.
