# weargear

Script name: `weargear`

Puts a gear set back on from wherever the pieces are. `.weargear` re-wears the standard set, `.weargear name` another set from the Gear Sets page. It exists for the day a script dies between stripping your armour and putting it back.

## How to start it

Type `.weargear` in the game window.

## Settings

This script has no settings of its own. Shared pages such as [Character](/studio/character.md), [Magic](/studio/magic.md) and [Crafting](/studio/crafting.md) may still apply.
