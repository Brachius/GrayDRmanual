# carve-bead

Script name: `carve-bead`

Carves a prayer bead for the Theurgy page's aspect. Words: `debug`, `primer` (use the carving primer), or an aspect name.

## How to start it

Type `.carve-bead` in the game window.

## Settings

This script has no settings of its own. Shared pages such as [Character](/studio/character.md), [Magic](/studio/magic.md) and [Crafting](/studio/crafting.md) may still apply.
