# carve-bead

Script name: `carve-bead`

Carves a prayer bead for your immortal's aspect with the carving knife from the Theurgy page. Words: `primer` uses the carving primer, `debug` prints each step, an aspect name carves for that aspect instead.

## How to start it

Type `.carve-bead` in the game window.

## Settings

This script has no settings of its own. Shared pages such as [Character](/studio/character.md), [Magic](/studio/magic.md) and [Crafting](/studio/crafting.md) may still apply.
