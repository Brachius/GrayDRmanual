# trader-perc

Script name: `trader-perc`

One Attunement pass over the Trader perceive targets (mana, planets, illusion). Does nothing when Attunement is already mind locked.

## How to start it

Type `.trader-perc` in the game window.

## Settings

This script has no settings of its own. Shared pages such as [Character](/studio/character.md), [Magic](/studio/magic.md) and [Crafting](/studio/crafting.md) may still apply.
