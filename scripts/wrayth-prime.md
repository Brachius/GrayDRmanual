# wrayth-prime

Script name: `wrayth-prime`

Sends the client controls that unlock the game's larger typeahead queue, then exits. No game commands. Runs by itself at login while **Prime client controls at login** is on (Character page).

## How to start it

Type `.wrayth-prime` in the game window.

## Settings

This script has no settings of its own. Shared pages such as [Character](../studio/character.md), [Magic](../studio/magic.md) and [Crafting](../studio/crafting.md) may still apply.
