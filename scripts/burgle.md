# burgle

Script name: `burgle`

Burgles a home: enters by lockpick or rope, searches the rooms, keeps or sells the loot, as set on the Studio's [Burgle page](/studio/burgle.md). Started by hand it keeps Lich Burgle's safety word so a typo cannot start a caper; from a Master Train card no word is needed.

## How to start it

Type `.burgle` in the game window.

## Settings

This script has no settings of its own. Shared pages such as [Character](/studio/character.md), [Magic](/studio/magic.md) and [Crafting](/studio/crafting.md) may still apply.
