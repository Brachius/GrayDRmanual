# om

Script name: `om`

Creates and loads an Osrel Meraud from one exact deity favor orb. It never uses a bare `get my orb`, which could pick up an unrelated memory orb.

## How to start it

Type `.om` in the game window.

## Settings

This script has no settings of its own. Shared pages such as [Character](../studio/character.md), [Magic](../studio/magic.md) and [Crafting](../studio/crafting.md) may still apply.
