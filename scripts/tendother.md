# tendother

Script name: `tendother`

Binds another character's wounds and keeps the bandages up for their run: `.tendother Name`.

## How to start it

Type `.tendother` in the game window.

## Settings

This script has no settings of its own. Shared pages such as [Character](/studio/character.md), [Magic](/studio/magic.md) and [Crafting](/studio/crafting.md) may still apply.
