# validate

Script name: `validate`

Checks this character's whole configuration against the data files (skill names, spells, the map, activities, the gear list, hunting zones, crafting tools) and prints every value that cannot be right. Reads only; nothing is sent to the game.

## How to start it

Type `.validate` in the game window.

## Settings

This script has no settings of its own. Shared pages such as [Character](../studio/character.md), [Magic](../studio/magic.md) and [Crafting](../studio/crafting.md) may still apply.
