# Ingredient Gathering

Script name: `alchemy`

Native port of alchemy.lic forage and preparation workflows.

## How to start it

Type `.alchemy` followed by the words it takes.

ingredient [forage] [prepare] [quantity]

Example:

```
.alchemy aloe forage prepare 25
```

In Master Train, pick **Alchemy Ingredients** as the activity and put the same words in its Arguments box.

## Settings

On the Configuration Studio page [Crafting](/studio/crafting.md):

| Setting | What it does | Default | Applies to |
|---|---|---|---|
| **Forage quantity** | A number, at least 1. | 6 | Global, or each character |
| **Forage room override** | A number, at least 0. Must be a room on the map. | 0 | Global, or each character |
| **Forage style** |  | (not set) | Global, or each character |
| **Forage town override** |  | (not set) | Global, or each character |
| **Preparation quantity** | A number, at least 1. | 25 | Global, or each character |
| **Raw herb storage** |  | (not set) | Global, or each character |
