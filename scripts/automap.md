# automap

Script name: `automap`

Records the moves you make by hand so the Data Editor can put them on the travel map. `.automap` starts recording, `.automap stop` ends it and says what was recorded, `.automap status` shows what is recorded so far. Carry a light. Nothing is sent to the game. See [Data Editor, Walks](../data-editor.md#walks).

## How to start it

Type `.automap` in the game window.

## Settings

This script has no settings of its own. Shared pages such as [Character](../studio/character.md), [Magic](../studio/magic.md) and [Crafting](../studio/crafting.md) may still apply.
