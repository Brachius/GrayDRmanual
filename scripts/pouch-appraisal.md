# pouch-appraisal

Script name: `pouch-appraisal`

Appraises the training gem pouches from the pouch source container and moves each finished one to the staging container, as set on the Gem Pouches page. With no pouch adjective configured it does nothing.

## How to start it

Type `.pouch-appraisal` in the game window.

## Settings

This script has no settings of its own. Shared pages such as [Character](/studio/character.md), [Magic](/studio/magic.md) and [Crafting](/studio/crafting.md) may still apply.
