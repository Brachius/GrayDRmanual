# Moon Mage Perceive

Script name: `moon-perc`

One Attunement pass over the Moon Mage perceive targets; skipped when Attunement is mind locked.

## How to start it

Type `.moon-perc` in the game window.

In Master Train, pick **Moon Mage Perceive** as the activity and put the same words in its Arguments box.

## Settings

This script has no settings of its own. Shared pages such as [Character](/studio/character.md), [Magic](/studio/magic.md) and [Crafting](/studio/crafting.md) may still apply.
