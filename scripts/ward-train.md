# Warding Magic Training

Script name: `ward-train`

Trains Warding the same way Utility training works, with the Warding entry under **Training spells** on the Magic page. A ward that will not take because another ward is up is a stop; put that ward under **Release before training**.

## How to start it

Type `.ward-train` in the game window.

In Master Train, pick **Warding magic** as the activity and put the same words in its Arguments box.

## Settings

This script has no settings of its own. Shared pages such as [Character](/studio/character.md), [Magic](/studio/magic.md) and [Crafting](/studio/crafting.md) may still apply.
