# Deed Sorting (Hollow Eve)

Script name: `deed-sort`

Hand sack deeds to their keepers, then rebuild each keeper's register into full-size deeds.

## How to start it

Type `.deed-sort` followed by the words it takes.

nothing for the party, or tidy.

Example:

```
.deed-sort tidy
```

In Master Train, pick **Deed Sorting** as the activity and put the same words in its Arguments box.

## Settings

This script has no settings of its own. Shared pages such as [Character](/studio/character.md), [Magic](/studio/magic.md) and [Crafting](/studio/crafting.md) may still apply.
