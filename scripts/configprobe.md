# configprobe

Script name: `configprobe`

Prints the settings the combat scripts depend on, so they can be pasted into a report when something is wrong. Reads only; nothing is sent to the game.

## How to start it

Type `.configprobe` in the game window.

## Settings

This script has no settings of its own. Shared pages such as [Character](/studio/character.md), [Magic](/studio/magic.md) and [Crafting](/studio/crafting.md) may still apply.
