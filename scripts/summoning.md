# Summoning Training

Script name: `summoning`

Train Warrior Mage Summoning by summoning and breaking weapons, then focusing the pathway.

## How to start it

Type `.summoning` in the game window.

In Master Train, pick **Summoning training** as the activity and put the same words in its Arguments box.

## Settings

On the Configuration Studio page [Magic](/studio/magic.md):

| Setting | What it does | Default | Applies to |
|---|---|---|---|
| <span id="setting-activities-summoning-max-threshold"></span>**Summoning maximum mindstate** | Never train Summoning past this mind state, whatever the increment says. A number, at least 0, at most 34. | 28 | Global, or each character |
| <span id="setting-activities-summoning-target-increment"></span>**Summoning target increment** | How many mind states Summoning should gain in one run before the step ends. A number, at least 1, at most 34. | 17 | Global, or each character |
