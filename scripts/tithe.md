# tithe

Script name: `tithe`

Puts the tithe in the almsbox, as set on the Theurgy page. Theurgy training calls it by itself; run it alone to tithe now.

## How to start it

Type `.tithe` in the game window.

## Settings

This script has no settings of its own. Shared pages such as [Character](../studio/character.md), [Magic](../studio/magic.md) and [Crafting](../studio/crafting.md) may still apply.
