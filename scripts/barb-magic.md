# Barbarian Magic

Script name: `barb-magic` (also starts as `Barb_Magic`)

Activate an ordered list of Barbarian abilities for training.

## How to start it

Type `.barb-magic` in the game window.

In Master Train, pick **Barbarian Magic** as the activity and put the same words in its Arguments box.

## Settings

On the Configuration Studio page [Buffs](../studio/buffs.md):

| Setting | What it does | Default | Applies to |
|---|---|---|---|
| **Barbarian training abilities** |  |  | Global, or each character |
| &nbsp;&nbsp;&nbsp;&nbsp;↳ **Abilities in activation order** _(required)_ | A list. | (not set) | Global, or each character |
| &nbsp;&nbsp;&nbsp;&nbsp;↳ **Sit for meditations** | Yes or No. | No | Global, or each character |
