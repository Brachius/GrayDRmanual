# Gem Pouches

Configuration Studio page **Gem Pouches**. Open it from the left-hand list; type part of a setting's name in the search box to find it.

The appraisal pouches, the hunting pouch, and spare pouches.

Scripts that read these settings: [Combat Trainer](/scripts/combat-trainer.md).

| Setting | What it does | Default | Applies to |
|---|---|---|---|
| <span id="setting-autoloot-fill-gem-pouch-delay"></span>**Autoloot fill gem pouch delay** | How frequently to fill your gem pouch with your autolooter in combat | (not set) | Global, or each character |
| <span id="setting-activities-pouch-adjective"></span>**Appraisal pouch adjective** | Leave blank to make pouch-appraisal a clean no-op. | (blank) | Each character |
| <span id="setting-full-pouch-container"></span>**Full pouch container** | Container for full gem pouches. | (not set) | Global, or each character |
| <span id="setting-gem-pouch-adjective"></span>**Hunting gem pouch adjective** | Adjective of the normal-gemshop pouch used for gems collected while hunting. Sell Loot and every hunting pouch consumer share this value. | (not set) | Global, or each character |
| <span id="setting-gem-pouch-noun"></span>**Hunting gem pouch noun** | Noun of the normal-gemshop pouch used for hunting gems; normally pouch. Sell Loot and every hunting pouch consumer share this value. | (not set) | Global, or each character |
| <span id="setting-activities-pouch-noun"></span>**Appraisal pouch noun** | Normally pouch. | pouch | Each character |
| <span id="setting-activities-pouch-source"></span>**Appraisal pouch source** | Container holding unappraised training pouches. | (blank) | Each character |
| <span id="setting-activities-pouch-processed"></span>**Appraisal pouch staging** | Temporary container that prevents appraising the same pouch twice. | (blank) | Each character |
| <span id="setting-spare-gem-pouch-container"></span>**Spare gem pouch container** | Container for spare gem pouches. | (not set) | Global, or each character |
| <span id="setting-tie-gem-pouches"></span>**Tie gem pouches** | Controls tie gem pouches behavior in Combat Trainer. Yes or No. | (not set) | Global, or each character |
| <span id="setting-activities-spare-pouch-container"></span>**Spare gem-pouch container** | Container stocked with replacement hunting pouches. | (blank) | Each character |
| <span id="setting-activities-spare-pouch-target"></span>**Spare gem-pouch target** | Number of spare hunting pouches to keep. A number, at least 0, at most 50. | 5 | Each character |
| <span id="setting-activities-pick-box-pouch-adjective"></span>**Box-picking gem pouch adjective** | Adjective of the financed-gemshop pouch dedicated to loot from opened boxes. Pick treats its noun as the fixed word pouch. | (blank) | Each character |
