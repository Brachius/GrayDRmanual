# Performance

Configuration Studio page **Performance**. Open it from the left-hand list; type part of a setting's name in the search box to find it.

The instrument, its cleaning cloth, and the mind state goal.

Scripts that read these settings: [Performance](../scripts/performance.md).

| Setting | What it does | Default | Applies to |
|---|---|---|---|
| **Hand armor to remove** | Required only when a held instrument is configured. | (blank) | Global, or each character |
| **Held instrument** | Optional instrument that must be removed and held to play. | (blank) | Global, or each character |
| **Perform while healing** | Yes or No. | No | Global, or each character |
| **Performance worn instrument** | Instrument played while worn; normally zills. | zills | Each character |
| **Performance cleaning cloth** | Cloth used when the instrument reports dirt or moisture. | chamois cloth | Each character |
| **Performance mindstate goal** | Standalone default; a numeric script argument overrides it. A number, at least 1, at most 34. | 31 | Each character |
