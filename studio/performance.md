# Performance

Configuration Studio page **Performance**. Open it from the left-hand list; type part of a setting's name in the search box to find it.

The instrument, its cleaning cloth, and the mind state goal.

Scripts that read these settings: [Performance](/scripts/performance.md).

| Setting | What it does | Default | Applies to |
|---|---|---|---|
| <span id="setting-activities-performance-hand-armor"></span>**Hand armor to remove** | Required only when a held instrument is configured. | (blank) | Global, or each character |
| <span id="setting-activities-performance-held-instrument"></span>**Held instrument** | Optional instrument that must be removed and held to play. | (blank) | Global, or each character |
| <span id="setting-activities-performance-while-healing"></span>**Perform while healing** | Yes or No. | No | Global, or each character |
| <span id="setting-activities-performance-instrument"></span>**Performance worn instrument** | Instrument played while worn; normally zills. | zills | Each character |
| <span id="setting-activities-performance-cleaning-cloth"></span>**Performance cleaning cloth** | Cloth used when the instrument reports dirt or moisture. | chamois cloth | Each character |
| <span id="setting-activities-performance-goal"></span>**Performance mindstate goal** | Standalone default; a numeric script argument overrides it. A number, at least 1, at most 34. | 31 | Each character |
