# Athletics

Configuration Studio page **Athletics**. Open it from the left-hand list; type part of a setting's name in the search box to find it.

Which route Athletics trains on and what to hold while climbing.

Scripts that read these settings: [Athletics](../scripts/athletics.md).

| Setting | What it does | Default | Applies to |
|---|---|---|---|
| **Athletics town** |  | (blank) | Global, or each character |
| **Avoid justice areas** | Yes or No. | No | Global, or each character |
| **Carry a climbing rope** | Yes or No. | No | Global, or each character |
| **Climbing rope adjective** |  | climbing | Global, or each character |
| **Climbing target** |  | practice rope | Global, or each character |
| **Outdoorsmanship room IDs** | Semicolon-delimited stable room IDs. | (blank) | Global, or each character |
| **Swimming target** |  | river | Global, or each character |
| **Athletics route** | auto, wyvern, xalas, undergondola, or cliffs. | auto | Each character |
| **Athletics held items** | Semicolon-separated items retrieved for Athletics and stowed afterward. | (blank) | Each character |
