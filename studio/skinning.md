# Skinning

Configuration Studio page **Skinning**. Open it from the left-hand list; type part of a setting's name in the search box to find it.

Selling the skin bundle.

Scripts that read these settings: [Combat Trainer](/scripts/combat-trainer.md).

| Setting | What it does | Default | Applies to |
|---|---|---|---|
| <span id="setting-skinning"></span>**Skinning** | Hash of skinning related settings. A table of name and value pairs. | (not set) | Global, or each character |
| <span id="setting-activities-sell-bundle"></span>**Sell skin bundle** | Sell a nonempty worn bundle at the configured town tannery. Yes or No. | Yes | Each character |
