# Gear Sets

Configuration Studio page **Gear Sets**. Open it from the left-hand list; type part of a setting's name in the search box to find it.

Named sets of worn items, such as the set called standard, that scripts put back on after they strip gear. Auto-fill standard gear set copies the Gear page into the standard set.

| Setting | What it does | Default | Applies to |
|---|---|---|---|
| <span id="setting-gear-sets"></span>**Named gear sets** | Map each set name (for example standard) to the full descriptions of items that should be worn. A table of name and value pairs. | (not set) | Global, or each character |
