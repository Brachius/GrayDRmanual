# Scholarship Training

Configuration Studio page **Scholarship Training**. Open it from the left-hand list; type part of a setting's name in the search box to find it.

The almanac and the books used for Scholarship.

Scripts that read these settings: [Combat Trainer](/scripts/combat-trainer.md), [Scholarship Training](/scripts/scholarship-train.md).

| Setting | What it does | Default | Applies to |
|---|---|---|---|
| **Scholarship study items** | What the character studies. The book alone is enough; the Tome of Lore is an extra first step for characters that own one. |  | Global, or each character |
| &nbsp;&nbsp;&nbsp;&nbsp;↳ **Tome of Lore item** | Noun of the Tome of Lore to study first. Leave blank when the character has none. | (not set) | Global, or each character |
| &nbsp;&nbsp;&nbsp;&nbsp;↳ **Study book** | The crafting book to read page by page. | tailoring book | Global, or each character |
| &nbsp;&nbsp;&nbsp;&nbsp;↳ **Study chapter** | The chapter whose pages are read; it wraps to page 1 when the chapter ends. A number, at least 1. | 2 | Global, or each character |
| **Almanac noun** | The noun of your almanac. | (not set) | Global, or each character |
| **Almanac priority skills** | Controls almanac priority skills behavior in Combat Trainer. | (not set) | Global, or each character |
| **Almanac skills** | List of skills to turn almanac to train. A list. | (not set) | Global, or each character |
